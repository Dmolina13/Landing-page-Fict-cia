# 🚀 Landing Page Fictícia

Landing page responsiva de uma empresa fictícia, desenvolvida para praticar **HTML5, CSS3 e boas práticas de Frontend**, com foco em layout organizado e código limpo.

🔗 **Ver o site no ar:** https://dmolina13.github.io/Landing-page-Fict-cia/

## 🛠️ Tecnologias

- **HTML5** – estrutura semântica da página
- **CSS3** – estilização e layout responsivo [Flexbox / Grid / media queries]
- **GitHub** – versionamento e publicação

## ✨ Funcionalidades

- Layout responsivo (desktop, tablet e celular)
- [Seção de destaque (hero) com chamada para ação]
- [Seções de serviços/produtos]

## 📚 O que eu pratiquei

- Estruturação de páginas com tags semânticas
- Criação de layouts responsivos
- Organização de arquivos e código CSS
- Versionamento com commits e GitHub

## ▶️ Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/Dmolina13/Landing-page-Fict-cia.git

# Entre na pasta
cd Landing-page-Fict-cia

# Abra o arquivo index.html no navegador
```
